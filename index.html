03 / Course Rubric

Four Implemented CSS3 "Extras"

Advanced stylesheet capabilities engineered for accessibility, fluid scaling, and user preference adaptation.

01

Automatic Dark Mode

Combines CSS Custom Properties (:root) with @media (prefers-color-scheme: dark) to seamlessly shift the entire palette to a high-contrast slate theme.

02

Fluid Typography & Spacing

Uses mathematical clamp() functions for headings and section padding so typography scales proportionally with viewport width.

03

Reduced Motion Accessibility

Detects @media (prefers-reduced-motion: reduce) to disable smooth scrolling, hover elevations, and blinking cursors for vestibular comfort.

04

Custom Print Stylesheet

Implements @media print to hide navigation bars and buttons while reformatting cards into crisp, ink-friendly monochrome blocks.
